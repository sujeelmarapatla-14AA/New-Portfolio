# Sujeel Marapatla — Developer Portfolio

A cinematic, interactive developer portfolio featuring a 3D animated hero section and a tactile Folder-Tab architectural interface. Built for showcasing AI & Machine Learning work, full-stack systems, projects, and verified credentials.

## 🚀 Features

- **Cinematic Red Hero**: High-energy character animation with interactive red canvas particles and smooth audio wave integration.
- **Folder Tab Portfolio Architecture**: Interactive physical folder tab design with smooth sheet switching and responsive navigation.
- **About Section**: Comprehensive academic background, highlights, and verified contact links.
- **Technical Skills**: Interactive categorized technical skills (Python, C, Java, SQL, React, AI/ML tools).
- **Featured Projects**: Interactive project cards (AWS Trek, CareQ, OneProfile, Vault) with modal previews and direct GitHub links.
- **Verified Certifications**: Compact certification showcase featuring official credentials (JioPC AI Foundation, Autodesk Fusion, CIE MLRIT, MongoDB Credly).
- **Premium Platform Cards**: Official vector brand logos for GitHub, LinkedIn, Instagram, Email, and Location with interactive hover transitions.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Vanilla CSS + Tailwind CSS utilities
- **Design System**: Folder Tab Interactive Architecture

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
